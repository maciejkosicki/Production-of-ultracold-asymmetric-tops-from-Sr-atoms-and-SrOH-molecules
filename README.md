# Data Repository

This repository contains data associated with the following
research article published in Physical Chemistry Chemical Physics (PCCP):

**Production of ultracold asymmetric tops from Sr atoms and SrOH molecules**

Maciej B. Kosicki, Mateusz Borkowski, Marcin Umiński, and Piotr S. Żuchowski

*Physical Chemistry Chemical Physics*, 2025, **27** (47), 25389–25404.

DOI: [10.1039/D5CP03185K](https://doi.org/10.1039/D5CP03185K)

The preprint is available on arXiv: [arXiv:2508.14543](https://arxiv.org/pdf/2508.14543).
